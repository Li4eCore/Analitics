# 📘 SQL: от основ до продвинутого уровня

> 📊 **Итоговый уровень:** Уверенное владение SQL для аналитики, бэкенд-разработки и решения реальных бизнес-задач. Репозиторий содержит структурированные конспекты, готовые скрипты и разбор тестовых заданий уровня Middle.

## 🎯 Чему научился / Приобретённые компетенции
- ✅ **Аналитические запросы:** Построение сложных `SELECT` с фильтрацией, группировкой (`GROUP BY`, `HAVING`), сортировкой и пагинацией (`LIMIT`/`OFFSET`).
- ✅ **Работа с несколькими таблицами:** Свободное применение всех типов `JOIN` (`INNER`, `LEFT/RIGHT`, `FULL`, `CROSS`) и операторов множеств (`UNION`, `INTERSECT`, `EXCEPT`).
- ✅ **Продвинутая логика:** Использование подзапросов, `CTE` (Common Table Expressions), условной логики (`CASE`), безопасной обработки `NULL` (`COALESCE`, `NULLIF`) и кванторов (`EXISTS`, `ANY`, `ALL`).
- ✅ **Оконные функции:** Глубокое понимание `PARTITION BY`, ранжирующих (`ROW_NUMBER`, `RANK`, `DENSE_RANK`), агрегатных и смещающих (`LAG`, `LEAD`) функций. Настройка фреймов (`ROWS`, `GROUPS`, `RANGE`), `FILTER` и `EXCLUDE`.
- ✅ **Управление данными и схемой:** Проектирование таблиц, наложение ограничений (`CONSTRAINTS`), модификация структуры (`ALTER`), `INSERT`/`UPDATE`/`DELETE`, чёткое понимание порядка выполнения SQL-операторов.
- ✅ **Базовая архитектура и администрирование:** Создание представлений (`VIEW`), написание пользовательских функций, работа с триггерами и логированием изменений, нормализация БД до 3НФ, экспорт/создание дампов.
- ✅ **Решение бизнес-кейсов:** Применение SQL для ABC-анализа, расчёта метрик конверсии, анализа нагрузки/заказов и прохождения тестовых заданий (Amazon, Альфа-Банк, Тинькофф).
