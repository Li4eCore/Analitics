# 📈 SQL for Data Analytics — Portfolio

> 🎯 **Цель репозитория:** Демонстрация навыков работы с данными: от извлечения и очистки до расчёта продуктовых метрик и подготовки датасетов для визуализации.
> 
> 🧭 **Роль:** Junior Data Analyst | SQL Developer (Analytics focus)

---

## 💼 Ключевые аналитические компетенции

### 🔍 Исследование и подготовка данных (Data Exploration & Wrangling)
- ✅ **Профилирование данных:** Быстрая оценка качества данных, поиск дубликатов, аномалий и `NULL`-значений.
- ✅ **Очистка и трансформация:** Приведение типов, нормализация строк, обработка пропусков через `COALESCE`/`NULLIF`, создание фичей для анализа.
- ✅ **Подготовка витрин:** Формирование плоских датасетов, готовых к загрузке в BI-системы (Tableau, Power BI, Metabase).

### 📐 Расчёт бизнес-метрик (Business Metrics)
| Метрика | Для чего используется | Реализованные техники |
|---------|----------------------|----------------------|
| **Retention / Churn** | Удержание и отток клиентов | Само-соединения, `DATE_TRUNC`, `INTERVAL`, `COUNT(DISTINCT)` |
| **Conversion Rate** | Конверсия воронки | `CASE WHEN`, агрегация с фильтрацией, `CTE` для этапов |
| **ARPU / ARPPU** | Средний чек и доход на пользователя | Агрегатные функции, деление с обработкой `NULL` |
| **Cohort Analysis** | Когортный анализ поведения | Группировка по датам первой покупки, `DATE_PART`, `JOIN` по когортам |
| **ABC/XYZ-анализ** | Сегментация товаров/клиентов | Оконные функции `SUM() OVER()`, `PERCENT_RANK`, кумулятивные итоги |
| **LTV (упрощённо)** | Пожизненная ценность клиента | Прогнозные расчёты на основе исторических транзакций |

### 🪟 Продвинутая аналитика (Window Functions Mastery)
- ✅ **Ранжирование:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()` — для выделения топ-N товаров, регионов, сотрудников.
- ✅ **Сравнение периодов:** `LAG()` / `LEAD()` — расчёт MoM, WoW, YoY динамики, detection трендов.
- ✅ **Скользящие агрегаты:** `AVG() OVER (ROWS BETWEEN ...)`, `SUM() OVER (...)` — сглаживание временных рядов, расчёт скользящего среднего.
- ✅ **Фреймы и точные расчёты:** Понимание разницы `ROWS` vs `RANGE`, использование `FILTER` и `EXCLUDE` для точечных метрик.

### 🧩 Сложная логика и оптимизация
- ✅ **Читаемость кода:** Замена вложенных подзапросов на `CTE` (Common Table Expressions) — стандарт для аналитических пайплайнов.
- ✅ **Условная логика:** `CASE` для сегментации, создания флагов и кастомных группировок.
- ✅ **Производительность:** Понимание порядка выполнения запроса (`FROM` → `WHERE` → `GROUP BY` → `SELECT`) для написания эффективных запросов на больших объёмах.
